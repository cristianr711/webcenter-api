✅ PASO 4: VERIFICAR QUE FUNCIONA

   Una vez que esté "Ready", prueba este endpoint en el navegador:

💡 TROUBLESHOOTING:

   Si Vercel dice "Error: No Build Output":
   → Vercel.json está configurado correctamente
   → Node 18.x está especificado en package.json
   → Debería funcionar

   Si API retorna 500 después de deployment:
   → Verifica que DB_PASS esté SIN espacios
   → Verifica que DB_HOST sea exactamente: gateway01.us-east-1.prod.aws.tidbcloud.com
   → Verifica que NODE_ENV = production
   → Espera 5 minutos a que Vercel complete la configuración

   Si no conecta a TiDB:
   → Verifica que las credenciales sean exactas
   → Verifica que firewall de TiDB permita conexiones desde Vercel
   → Prueba localmente primero (ya funciona)
